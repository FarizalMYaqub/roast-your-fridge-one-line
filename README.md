One line that roasts a fridge, written by a small Python program to `/output/entry.txt`: 132 characters, one line, about a door alarm that acts like it pays the electric bill when it is most of the bill.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
